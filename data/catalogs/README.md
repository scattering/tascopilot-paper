# Synthetic Core Catalog

No records were imported from private catalogs. All records in this directory
are authored software-test examples. They contain
no measurements, private catalog excerpts, copied paper text, or raw data.
Several identifiers are retained as regression keys; they do not establish real
paper-to-experiment links. The data-file paths deliberately have no supplied raw
files. Every record carries fixture provenance and candidate links remain candidates.

Use these records for catalog import, retrieval, schema, and fail-closed tests.
They cannot reproduce a scientific figure or support a scientific claim.
